# Telco Customer Churn Prediction Dashboard

A Streamlit dashboard for real-time customer churn analysis using the IBM Telco Customer Churn dataset.

## Features
- Loads live data via CSV URL (always up-to-date)
- Preprocessing & cleaning in-app
- Random Forest-based churn prediction
- Interactive input for custom churn prediction
- Feature importance visualization

## Live Data Source
- [IBM Telco Customer Churn dataset (CSV)](https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv)
